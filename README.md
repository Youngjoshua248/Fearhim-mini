# 💀 FEARHIM Mini — Proof-of-Concept Demo

This is a **mini application** designed to demonstrate and teach the core technologies behind the full **FEARHIM** capstone project. It was created as part of the Onboarding Phase for [YOUR PROGRAM NAME HERE], and will be shared in the Week 4 “Geek Out” demo fair.

---

## 🎯 Project Goals

This project:

- Demonstrates core concepts of the **React + Vite + Tailwind** frontend stack
- Lays the **foundation** for the full-featured FEARHIM capstone
- Provides a clean, teachable example for **beginners** and a launchpad for deeper discussions with more advanced devs

---

## 🧱 Tech Stack Overview

| Tool          | Role in the Project                           |
| ------------- | --------------------------------------------- |
| React         | JavaScript library for building UI components |
| Vite          | Lightning-fast frontend dev/build tool        |
| Tailwind CSS  | Utility-first CSS framework for styling       |
| Framer Motion | Animations and transitions in React           |
| Howler.js     | JS audio library for handling ambient sounds  |
| Git + GitHub  | Version control and code sharing              |

Each technology is used with **best practices** based on official docs.

---

## 🛠 Features Implemented

### ✅ 1. **Spinning Gothic Logo**

- Built with `Framer Motion`
- Uses animation loop for continuous rotation
- Teaches: `motion.div`, animation props, reusability

### ✅ 2. **Ambient Music Playback**

- Powered by `Howler.js`
- Controlled via toggle button
- Teaches: `useEffect`, event handling, managing assets

### ✅ 3. **Responsive UI**

- Built with `Tailwind CSS` utility classes
- Dark, minimal aesthetic
- Teaches: layout utilities, responsive design, dark mode

### ✅ 4. **React Architecture**

- Folder structure shows separation of concerns
- Components broken into logical pieces
- Teaches: `App.jsx`, `main.jsx`, component design

## 🚀 Getting Started

### Prerequisites

- Node.js installed
- Git (for version control)

### Local Setup

```bash
# Clone the repo
git clone https://github.com/Fearhim-mini/fearhim-mini.git
cd fearhim-mini

# Install dependencies
npm install

# Start the development server
npm run dev
```
